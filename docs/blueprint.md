# **App Name**: Commerce Copilot

## Core Features:

- User Authentication with RBAC: Secure user authentication with role-based access control (admin, manager) managed by Supabase. Database includes user roles to define access permissions.
- AI-Powered Admin Agent: AI Agent provides backoffice assistance and leverages SAP Commerce Cloud APIs, natural language processing (NLP), and n8n workflows. An LLM analyzes user queries, and decides which available "tool" to apply.
- Real-Time Chat Interface: Dual-panel UI for real-time chat and result display.
- Hugging Face Integration: Integrate Hugging Face LLM for natural language understanding to extract the user's intentions from natural language input, prior to formulating the appropriate action in SAP Commerce Cloud
- Chat History: Store, display and manage chat history.
- SAP Commerce Cloud API Integration: Connect to SAP Commerce Cloud APIs, enabling tasks such as product search, catalog modifications, and order management.
- Feedback Collection: Gather user feedback on AI Agent responses.

## Style Guidelines:

- Primary color: Dark electric blue (#7DF9FF) to evoke a technological feel.
- Background color: Dark navy blue (#1A1A2E) provides a professional and focused atmosphere.
- Accent color: Teal (#008080) for interactive elements, buttons and important information.
- Body and headline font: 'Inter', a sans-serif font for a clear and modern appearance.
- Code font: 'Source Code Pro' for displaying code snippets or configurations.
- Dual-panel layout, with chat panel on the left and a results/details panel on the right.
- Use flat, outline-style icons.
